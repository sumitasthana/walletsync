# PNC Data Folder

## What is here

- `cards.json` - hand-maintained manifest of PNC's personal card lineup,
  in the standard 10-field raw schema. PNC's site blocks automated access
  from this machine (see `docs/reports/pnc_spike.md`), so the manifest is
  the card source instead of a scraper. Verified against the live listing
  page on 2026-09-10.
- `cards_clean.json` - generated by
  `python src/scraper/clean_data.py --bank pnc`.
- `raw/` - pricing and rewards document dumps. Empty until documents are
  captured (see below).

## Lineup covered

| Card | Rewards program |
|---|---|
| PNC Cash Rewards Visa | 4% gas / 3% restaurants / 2% groceries, first $8,000 combined annually, 1% other |
| PNC Cash Unlimited Visa Signature | flat 2%, no foreign transaction fee |
| PNC Spend Wise Visa | none (purchase APR reduction card) |
| PNC Secured Visa | none (credit builder) |

PNC Core and PNC points are not listed for online applications and are
intentionally out of scope.

## Manual capture step (blocker for extraction)

The dump scripts cannot download from pnc.com from this machine. To unblock
pricing and rewards extraction, download these PDFs in a browser and save
them under `data/pnc/raw/documents/` (any filename):

1. https://www.pnc.com/content/dam/pnc-com/pdf/personal/CreditCards/cash-rewards-rates.pdf
2. https://www.pnc.com/content/dam/pnc-com/pdf/personal/CreditCards/Agreement-Cash-Unlimited-Credit-Card.pdf
3. https://www.pnc.com/content/dam/pnc-com/pdf/personal/CreditCards/spend-wise-rates.pdf
4. https://www.pnc.com/content/dam/pnc-com/pdf/personal/CreditCards/secured-rates.pdf
5. https://www.pnc.com/content/dam/pnc-com/pdf/personal/CreditCards/cash-rewards-terms-conditions.pdf
6. https://www.pnc.com/content/dam/pnc-com/pdf/personal/CreditCards/cash-unlimited-terms-conditions.pdf

Items 1 to 4 are pricing documents (standard Schumer Box, per the spike).
Items 5 and 6 are rewards program terms. Once captured, the deterministic
PDF pricing parser and the tier 1 rewards extraction can run against them.

Note: the Cash Unlimited pricing link points to the pricing addendum
agreement PDF; the card's own "Rates and Fees" PDF link should be
confirmed and swapped in during the first capture.
